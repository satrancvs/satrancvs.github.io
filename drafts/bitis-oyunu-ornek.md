In the game Capablanca–Ragozin, Moscow 1936, White formulated his plan very concisely: stop the c-pawn from advancing, control the board up to the fifth rank, and only then push the queenside pawns.

{ Capablanca's own plan: king to e3, rook to c3, knight to d4, pawns to b4 and f4; then the queenside pawns can advance. The variations did not interest him, nor the speed of reaching that set-up. }
1. Nd4 Rb7 2. b4 Bd7 3. f4 Ke7 4. Kf2 Ra7 5. Rc3 Kd6 6. Rd3 Ke7 7. Ke3 Ra4 8. Rc3 Kd6
{ The planned set-up is complete. Now White must bring his king to the aid of the pawns he wants to advance. }
9. Rd3 Ke7 10. Rc3 Kd6
{ On repeating moves: in the endgame one should not hurry; repeating moves gives the active side psychological gains and lets the position be clarified. }
11. Ne2 g6 12. Rd3+ Ke6 13. Kd4 Ra6 14. Re3+ Kd6 15. Nc3 f5 16. b5 Ra8 ( 16... Rxa3 17. Ne4+ )
{ The pawns begin to advance with the pieces supporting them. Black cannot take on a3 because of Ne4+. }
17. Kc4 Be6+ 18. Kb4 c5+ 19. bxc6 Bg8 20. Nb5+ Kxc6 21. Rd3
{ White can now manage without advancing the a-pawn. Black's kingside pawns are weak, and one of them falls. }
21... g5 22. Rd6+ Kb7 23. fxg5 hxg5 24. Rf6 Rf8
{ A very important move: Capablanca takes away every chance of counterplay with ...f3. }
25. Rxg5 f4 26. Nd4 Rc8 27. Rg7+ Kb6 28. Rg6+ Kb7 29. Nb5 Rf8 30. Nd6+ Kb8 31. h4 1-0

### Capablanca–Reshevsky, Nottingham 1936

White is better: Black has an isolated pawn and weak dark squares on the queenside, especially c5. The winning plan is to bring the king to d4 and the knight to c3, and Black would be in zugzwang. But White's position also has a weak point: the rook's pawn on h4 is the "hook" that lets Black create counterplay. This classic ending was annotated by Bondarevsky in *Shakhmatny Bulletin*, 1973, No. 1.

1... g5! { White must fix the kingside pawn structure; otherwise Black would give White a weak pawn by exchanging on h4. }
2. hxg5 ( 2. h5 ) 2... fxg5
{ After 3 f4 gxf4 4 exf4 d4! Black would lose the d-pawn in time, but his bishop becomes active and the limited material gives good drawing chances. }
3. Nb4 axb3 4. axb3 Bb7
5. g4 { [D] The position has clarified. Black's only counter-chance is ...h5, which can be prepared in two ways: by advancing the rook's pawn with the king (played in the game), or by centralizing the king and supporting ...h5 with the bishop. }
5... Kg7 6. Ke2 Kg6 7. Kd3 h5 8. gxh5+ Kxh5 9. Kd4 Kh4 10. Nxd5 Kg3
{ Black's idea becomes clear: he has counterplay on the kingside. }
11. f4 g4 ( 11... Bxd5 12. Kxd5 g4 13. f5 Kh3 14. f6 g3 15. f7 g2 16. f8=Q g1=Q 17. Qh8+ Kg2 18. Qg8+ )
12. f5 Bc8 ( 12... Bc6 13. Nc7 )
13. Ke5 Bd7 14. e4 ( 14. Nc7 Bxf5 15. Kxf5 Kf3 ) 14... Be8
15. Kd4? ( 15. f6! Kf3 16. Nf4 g3 17. Kf5 Bd7+ 18. Kg5 Be6 19. Nxe6!! g2 20. f7 g1=Q+ 21. Kf6 )
{ A mistake, noticed only by Bondarevsky. }
15... Kf3 16. e5 g3 17. Ne3
{ [D] }
17... Kf4? ( 17... Bd7? 18. e6 Bc6 19. e7 Bd7 20. f6 Be8 21. Nf5 ) ( 17... Bf7!! 18. e6 Bg8 19. e7 ( 19. b4 Kf4! ) 19... Bf7 20. f6 Kf4! )
{ The decisive mistake in a drawn position. Alekhine showed that 17...Bd7 loses, but Bondarevsky found a draw with the brilliant 17...Bf7!!, by which Black gains a tempo for playing his king to f4. The rest of the game is clear without explanation. }
18. e6 g2 19. Nxg2+ Kxf5 20. Kd5 Kg4 21. Ne3+ Kf4 22. Kd4 1-0
</pgn>

{ Black resigned, since there is no defence against 23 e7 followed by the transfer of the knight to c7. }

The second possible plan was 5...Kf7 6 Ke2 Kf6 7 Kd3 Ke5. As Bondarevsky pointed out, White must then reckon with ...d4 followed by ...Kf4: 8 Nc2 Bc6 9 Nd4 Be8 10 Kc3 h5 11 gxh5 Bxh5 12 Kb4 g4 13 fxg4 Bxg4 14 Kxb5 Ke4 15 Kc5 Kxe3, and Black gains a draw. In practice the general assessment of the position matters more than calculating all these lines. Had Reshevsky chosen the second path, he would have drawn: centralizing the king does not always give the desired result, but in most cases it is necessary.
